# Project Name: Твоя ждуля

Description 

«Твоя ждуля» — это специализированное мобильное приложение для Android, разработанное для эмоциональной поддержки и организации времени людей, ожидающих возвращения близких. Приложение позволяет вести список контактов с автоматическим расчетом дней до даты их освобождения, а также отслеживать ежедневное настроение через интерактивный календарь. Пользователи могут сохранять свои мысли в личном дневнике и планировать важные события, такие как свидания или передачи, получая уведомления за день до их наступления. Для поднятия настроения в интерфейс интегрировано получение случайных изображений животных через внешнее API.

Installation 

Для локальной установки и запуска проекта выполните следующие шаги:

1. **Клонируйте репозиторий**: используйте команду `git clone` для копирования проекта на ваш компьютер.
2. **Откройте проект**: запустите Android Studio и выберите опцию «Open», указав путь к корневой папке проекта.
3. **Синхронизация Gradle**: дождитесь завершения процесса «Gradle Sync», чтобы установились все необходимые зависимости (Retrofit, Room, и др.).
4. **Запуск**: выберите подключенное устройство или эмулятор и нажмите кнопку «Run» (Shift+F10).

Usage 

После установки приложения следуйте этим рекомендациям для использования:

* **Добавление человека**: на главном экране нажмите «+ Добавить человека», введите имя и ожидаемую дату встречи.
* **Работа с календарем**: выберите добавленного человека из списка. Нажмите на текущую дату в календаре, чтобы выбрать цвет настроения и записать мысли в поле ввода.
* **Просмотр истории**: нажимайте на прошлые даты, чтобы прочитать сохраненные ранее записи (редактирование доступно только для текущего дня).
* **Планирование**: используйте кнопку «Запланировать встречу / передачку», чтобы отметить событие в будущем. Система автоматически создаст уведомление, которое придет за день до даты в 10:00 утра.
* **Обновление контента**: нажимайте на изображение котика или текст цитаты, чтобы загрузить новые данные из сети или локального хранилища.
